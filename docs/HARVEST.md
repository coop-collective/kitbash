# Harvest inventory

Written 2026-10-18 from three read-only scans of `~/Workspace` (49 folders triaged; 30 real apps or libraries;
worktree copies, `*-codex-security-scan*`, `platform-*` and `infx-*` variants excluded). Nothing in those repos was
modified. Paths are absolute; "golden" marks the implementation to start from when several exist.

**Reuse value** = how often it was rebuilt × how portable the best copy is × its quality × whether `kit-api` itself
needs it. **Effort** to extract into a tested block with a `hono-d1` variant: **S** ≤ ½ session, **M** 1 session,
**L** 2+ sessions (usually because two variants or a de-coupling are needed).

## The house stack (what every variant must target first)

Cloudflare Workers; Hono or a raw Worker (Next.js via OpenNext or vinext for sites); D1 with hand-written SQL and
`NNNN_name.sql` migrations (no ORM anywhere except align's Kysely and nextjs-template's drizzle scripts); R2; KV;
Durable Objects (SQLite) as single-writer locks; Queues and cron; Cloudflare Email Service (`send_email` binding);
vitest 4 in workerd via `@cloudflare/vitest-pool-workers`; pnpm. Stripe is called over `fetch` without the SDK in
three repos. PostHog is used without the SDK in two. No app imports a shared package from another app (the published
`typescript-agent-toolkit` has zero internal users).

## Anti-patterns found (do not harvest as-is)

- `platform/packages/website`: a 3,205-line Stripe webhook in one file; `auth.ts` at 1,053 lines with admin
  hard-coded by email domain in 39 places; Jam-specific permissions in the org model.
- `inference-market/packages/web/migrations`: duplicate `0030_*` files, gaps (0031–32, 0040, 0046, 0057–66) and
  `SELECT 1;` placeholders. The block spec forbids this (migrations renumber on copy; a version never edits one).
- `placer` email codes: `% 1_000_000` without rejection sampling (biased); KV-only codes.
- `mailcheap`: a Mongo-style document layer over D1 (`lib/d1-model.js`) and JavaScript; it is a fork of
  `marclou/mailcheap` (MIT), so anything harvested carries `provenance.origin: packaged-oss` and attribution.
- `nextjs-template`: has drifted into a specific app (`coopalove`, hard-coded hostname); the auth starter is unwired
  and untested. Use `platform/packages/seed/app-templates/webapp-nextjs-template` as the template ancestor instead.
- `ideator/src/mcp.ts`: org switching by monkey-patching `server.registerTool`; extract a `wrap(handler)`.

## Harvest rules (for the Harvester skill)

1. Start from the golden source; port the hygiene of the alternates (HMAC'd codes, attempt-before-compare, idempotent
   refs) rather than their code.
2. Extract params for every app-specific literal: brand/app name, token prefix, table prefix, route prefix, domain,
   limits. If the literal can't be a param, it's a variant or it isn't a block.
3. Tests travel with the code or the block doesn't ship. Where the source has none (nextjs-template, platform orgs),
