Billing, catalog MIME capabilities, signed upstream reference URLs, 24-hour application TTL and multipart holds are a different feature and were removed.

The extracted block intentionally serves arbitrary bytes as private attachments rather than copying either app's public-image/reference policy. It hashes tenant ids before key construction, ignores caller filenames and MIME, uses fixed safe download headers, and never publishes a URL to the R2 bucket. Body buffering uses one fixed maximum-sized buffer instead of retaining an attacker-controlled count of tiny chunk objects. It writes only after a complete read; downloads remain streams. UUID creation avoids the source reference generator's modulo bias.

Anti-patterns: trusting Content-Length alone; unbounded request.arrayBuffer/formData; embedding user path fragments in keys; authenticating a user without checking selected-org membership; enabling public R2 access on private assets; reflecting arbitrary Content-Type/disposition/cache metadata; assuming a per-file cap is a total-tenant quota.
